# 🧠 Análisis Fractal y Dinámica No Lineal de Señales EEG en Reposo  
**Control vs DCL (Deterioro Cognitivo Leve)**

Este repositorio contiene códigos en Python y datos EEG utilizados para el análisis, visualización y generación de **representaciones fractales y caóticas** de señales electroencefalográficas (EEG) registradas en estado de reposo.

---

## 📌 Descripción General

Se analizan **señales EEG en reposo de 5 minutos** correspondientes a:

- 🟢 **Grupo Control**
- 🔵 **Grupo DCL (Deterioro Cognitivo Leve)**

Las señales se registran en distintas **regiones cerebrales**.  
De cada registro continuo de 5 minutos se extraen **recortes de 1 minuto por área cerebral**.
